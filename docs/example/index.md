# Example

Раздел `Example` не является отдельным сайтом или отдельной документацией.

Это ссылка на репозиторий DSA с готовыми примерами, где можно посмотреть, как правила из **DSA Core** и **Full Stack Guide** выглядят в реальном коде.

## Репозиторий с примерами

[https://github.com/Dubium-Design-System/dsa/tree/main/examples](https://github.com/Dubium-Design-System/dsa/tree/main/examples)

Примеры находятся в директории `examples` основного репозитория DSA.

Используйте их как эталон реализации: документация объясняет правило и причины, а репозиторий показывает законченную структуру файлов, связи между слоями и рабочий код.

::: tip
Если пример в репозитории и текст документации расходятся, это стоит считать проблемой документации или example-кода и исправлять их вместе.
:::
